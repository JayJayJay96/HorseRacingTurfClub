# Phase 2 — Private Rooms + Lobby Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A host opens a Private room on the big screen. Phones join by QR code or room code. The host ticks the roster, sets length and prize, and moves the room between LOBBY and SHOP, and every screen updates live.

**Architecture:** Supabase handles this phase:

- **Identity:** Supabase Auth anonymous sign-in gives every device a `uid`.
- **Tables:** two Postgres tables, `rooms` and `room_players`. Row-level security lets a device read only the rooms it hosts or has joined.
- **Writes:** every write goes through a `security definer` RPC that checks host, phase and limits. Clients never write tables directly.
- **Live updates:** clients subscribe to Postgres Changes for their room and refetch on any change. A Realtime presence channel shows which phones are online.
- **Cleanup:** pg_cron deletes rooms idle for more than 24 hours.

The app routes `/`, `/track`, `/play` and `/sandbox` by pathname, without a router dependency.

**Tech Stack:** Supabase (CLI 2.x local stack on Docker, Postgres, Auth anonymous, Realtime, pg_cron), `@supabase/supabase-js` 2.x, `qrcode`, React 19, Vite 8, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-29-horse-racing-turf-club-design.md` §2, §3, §4, §5 (LOBBY and SHOP rows), §12 phase 2.

## Scope decisions (read first)

- **Phase transitions in this phase:** `LOBBY→SHOP` needs at least 2 ticked horses. `SHOP→LOBBY` goes back. `PODIUM→LOBBY` starts the next race. Phase 3 adds `SHOP→ODDS_LOCKED→BETTING→RUNNING` through Edge Functions. The SHOP screen shows a "buying arrives next update" note and Ready ticks.
- **Identity:** Supabase anonymous sign-in, not custom tokens. Policies and RPCs use `auth.uid()`, and Phase 5 can link Office logins to the same users.
  - Anonymous sign-ins are rate-limited **per IP**, 30/hour by default.
  - Office phones share one IP, so Task 13 raises the hosted limit to 150. Local config uses 1000 because tests create many users.
- **Host device:**
  - A Private room is controlled by the device that created it, matching `rooms.host_uid`.
  - Spec §5 says "any device can reopen `/track`". For Private rooms that waits for a host-handover code (deferred, noted in PROJECT_STATUS).
  - Reopening `/track?code=…` on the **same** browser works.
- **Removed phones:** a removed phone is no longer a room member, so RLS hides the room from it. It sees "No room with that code" on its next refetch. That is acceptable for Phase 2.
- **Error contract:** RPCs raise plain snake_case codes such as `name_taken` or `not_host`. supabase-js puts the code in `error.message`, and `errorText()` maps codes to UI text.
- **Max horses:** 22 is hard-coded in SQL. It must match `MAX_HORSES` in `src/sim/config.ts`.
- **Max entries per room:** 40 (spam guard).

```ts
import { execSync } from 'node:child_process';
import { createClient, type SupabaseClient } from '@supabase/supabase-js';

/** Reads URL and keys of the running local stack (`npx supabase start`). */
function localEnv(): Record<string, string> {
  const out = execSync('npx supabase status -o env', { encoding: 'utf8' });
  const env: Record<string, string> = {};
  for (const line of out.split(/\r?\n/)) {
    const m = /^(\w+)="?(.*?)"?$/.exec(line.trim());
    if (m) env[m[1]!] = m[2]!;
  }
  return env;
}

const env = localEnv();
const URL = env.API_URL;
const ANON_KEY = env.ANON_KEY;
const SERVICE_KEY = env.SERVICE_ROLE_KEY;
if (!URL || !ANON_KEY || !SERVICE_KEY) {
  throw new Error(`Is the local stack running? supabase status gave: ${Object.keys(env).join(', ')}`);
}

const opts = { auth: { persistSession: false, autoRefreshToken: false } };

/** A device that has not signed in. */
export const guestClient = (): SupabaseClient => createClient(URL, ANON_KEY, opts);

/** A fresh anonymous user (one per simulated device). */
export async function anonClient(): Promise<SupabaseClient> {
  const client = guestClient();
  const { error } = await client.auth.signInAnonymously();
  if (error) throw error;
  return client;
}

/** Bypasses RLS. Test setup only. */
export const adminClient = (): SupabaseClient => createClient(URL, SERVICE_KEY, opts);

type Res<T> = PromiseLike<{ data: T | null; error: { message: string } | null }>;

/** Returns data or throws the error message (our RPC error code). */
export async function ok<T>(call: Res<T>): Promise<T> {
  const { data, error } = await call;
  if (error) throw new Error(error.message);
  return data as T;
}

/** Returns the error message of a call that must fail. */
export async function fails(call: Res<unknown>): Promise<string> {
  const { error } = await call;
  if (!error) throw new Error('expected the call to fail');
  return error.message;
}
```

`supabase/migrations/20261030000001_rooms.sql`:

```sql
-- Phase 2: Private rooms and lobby.
-- Clients may only SELECT rooms they belong to; every write goes through a security-definer RPC.
-- RPC errors are plain snake_case codes (mapped to UI text by src/net/rooms.ts errorText).

create schema if not exists private;
grant usage on schema private to authenticated;

create table public.rooms (
  id uuid primary key default gen_random_uuid(),
  code text not null unique check (code ~ '^[A-HJKMNP-Z2-9]{4}$'),
  host_uid uuid not null references auth.users (id) on delete cascade,
  phase text not null default 'LOBBY'
    check (phase in ('LOBBY', 'SHOP', 'ODDS_LOCKED', 'BETTING', 'RUNNING', 'PODIUM')),
  race_length text not null default 'short' check (race_length in ('short', 'long')),
  prize text not null default '' check (char_length(prize) <= 60),
  created_at timestamptz not null default now(),
  last_activity_at timestamptz not null default now()
);
create index rooms_host_uid_idx on public.rooms (host_uid);

-- uid is null for names the host typed (no phone).
create table public.room_players (
  id uuid primary key default gen_random_uuid(),
  room_id uuid not null references public.rooms (id) on delete cascade,
  uid uuid references auth.users (id) on delete set null,
  name text not null check (char_length(name) between 1 and 24 and name = btrim(name)),
  ticked boolean not null default false,
  ready boolean not null default false,
  joined_at timestamptz not null default now(),
  unique (room_id, uid)
);
create unique index room_players_room_name_key on public.room_players (room_id, lower(name));
create index room_players_uid_idx on public.room_players (uid);

revoke all on public.rooms, public.room_players from anon;
revoke insert, update, delete, truncate on public.rooms, public.room_players from authenticated;
grant select on public.rooms, public.room_players to authenticated;

create function private.is_room_member(p_room uuid)
returns boolean
language sql
stable
security definer
set search_path = ''
as $$
  select exists (select 1 from public.rooms where id = p_room and host_uid = auth.uid())
      or exists (select 1 from public.room_players where room_id = p_room and uid = auth.uid());
$$;
revoke execute on function private.is_room_member(uuid) from public;
grant execute on function private.is_room_member(uuid) to authenticated;

alter table public.rooms enable row level security;
alter table public.room_players enable row level security;

create policy "members read their room" on public.rooms
  for select to authenticated using (private.is_room_member(id));
create policy "members read their roster" on public.room_players
  for select to authenticated using (private.is_room_member(room_id));

-- Locks the room row, checks the caller is its host, and marks activity (keeps it from cleanup).
create function private.lock_host_room(p_room uuid)
returns public.rooms
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_room public.rooms;
begin
  if auth.uid() is null then
    raise exception 'not_signed_in';
  end if;
  select * into v_room from public.rooms where id = p_room for update;
  if not found then
    raise exception 'room_not_found';
  end if;
  if v_room.host_uid <> auth.uid() then
    raise exception 'not_host';
  end if;
  update public.rooms set last_activity_at = now() where id = p_room;
  return v_room;
end;
$$;
revoke execute on function private.lock_host_room(uuid) from public;

create function public.create_room(p_length text default 'short', p_prize text default '')
returns public.rooms
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_alphabet constant text := 'ABCDEFGHJKMNPQRSTUVWXYZ23456789'; -- no I, L, O, 0, 1
  v_prize text := btrim(coalesce(p_prize, ''));
  v_code text;
  v_room public.rooms;
begin
  if auth.uid() is null then
    raise exception 'not_signed_in';
  end if;
  if p_length is null or p_length not in ('short', 'long') then
    raise exception 'bad_length';
  end if;
  if char_length(v_prize) > 60 then
    raise exception 'prize_too_long';
  end if;
  for attempt in 1..20 loop
    v_code := '';
    for i in 1..4 loop
      v_code := v_code || substr(v_alphabet, 1 + floor(random() * 31)::int, 1);
    end loop;
    begin
      insert into public.rooms (code, host_uid, race_length, prize)
      values (v_code, auth.uid(), p_length, v_prize)
      returning * into v_room;
      return v_room;
    exception when unique_violation then
      -- code in use; try another
    end;
  end loop;
  raise exception 'no_free_code';
end;
$$;
revoke execute on function public.create_room(text, text) from public, anon;
grant execute on function public.create_room(text, text) to authenticated;

create function public.join_room(p_code text, p_name text)
returns public.room_players
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_room_id uuid;
  v_name text := btrim(coalesce(p_name, ''));
  v_player public.room_players;
begin
  if auth.uid() is null then
    raise exception 'not_signed_in';
  end if;
  select id into v_room_id from public.rooms where code = upper(btrim(p_code));
  if not found then
    raise exception 'room_not_found';
  end if;

  -- Same device again: return its entry (the name is ignored, so '' works as a rejoin probe).
  select * into v_player from public.room_players where room_id = v_room_id and uid = auth.uid();
  if found then
    return v_player;
  end if;

  if char_length(v_name) not between 1 and 24 then
    raise exception 'bad_name';
  end if;
  update public.rooms set last_activity_at = now() where id = v_room_id;

  -- A name the host typed (no phone yet) is claimed by the first phone that joins with it.
  update public.room_players set uid = auth.uid()
    where room_id = v_room_id and lower(name) = lower(v_name) and uid is null
    returning * into v_player;
  if found then
    return v_player;
  end if;

  if exists (select 1 from public.room_players where room_id = v_room_id and lower(name) = lower(v_name)) then
    raise exception 'name_taken';
  end if;
  if (select count(*) from public.room_players where room_id = v_room_id) >= 40 then
    raise exception 'room_full';
  end if;
  insert into public.room_players (room_id, uid, name)
  values (v_room_id, auth.uid(), v_name)
  returning * into v_player;
  return v_player;
exception when unique_violation then
  raise exception 'name_taken'; -- lost a race with a concurrent join of the same name
end;
$$;
revoke execute on function public.join_room(text, text) from public, anon;
grant execute on function public.join_room(text, text) to authenticated;
```

```sql
-- Host-driven phase changes. Phase 3 adds SHOP -> ODDS_LOCKED -> BETTING -> RUNNING via Edge Functions.

create function public.set_phase(p_room uuid, p_phase text)
returns public.rooms
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_room public.rooms := private.lock_host_room(p_room);
begin
  if v_room.phase || '>' || coalesce(p_phase, '') not in ('LOBBY>SHOP', 'SHOP>LOBBY', 'PODIUM>LOBBY') then
    raise exception 'bad_transition';
  end if;
  if p_phase = 'SHOP'
     and (select count(*) from public.room_players where room_id = p_room and ticked) < 2 then
    raise exception 'need_two_horses';
  end if;
  update public.room_players set ready = false where room_id = p_room and ready;
  update public.rooms set phase = p_phase where id = p_room returning * into v_room;
  return v_room;
end;
$$;
revoke execute on function public.set_phase(uuid, text) from public, anon;
grant execute on function public.set_phase(uuid, text) to authenticated;

create function public.set_ready(p_room uuid, p_ready boolean)
returns void
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_phase text;
begin
  if auth.uid() is null then
    raise exception 'not_signed_in';
  end if;
  -- FOR SHARE waits for a concurrent set_phase, so a stale Ready can't survive a phase change.
  select phase into v_phase from public.rooms where id = p_room for share;
  if not found then
    raise exception 'room_not_found';
  end if;
  if v_phase not in ('SHOP', 'BETTING') then
    raise exception 'wrong_phase';
  end if;
  update public.room_players set ready = coalesce(p_ready, false)
    where room_id = p_room and uid = auth.uid();
  if not found then
    raise exception 'not_in_room';
  end if;
end;
$$;
revoke execute on function public.set_ready(uuid, boolean) from public, anon;
grant execute on function public.set_ready(uuid, boolean) to authenticated;
```

```ts
export type Room = Database['public']['Tables']['rooms']['Row'];
export type RoomPlayer = Database['public']['Tables']['room_players']['Row'];

type Res<T> = PromiseLike<{ data: T | null; error: { message: string } | null }>;

async function call<T>(request: Res<T>): Promise<T> {
  const { data, error } = await request;
  if (error) throw new Error(error.message);
  return data as T;
}
```

`src/net/useRoom.ts`:

```ts
import { useCallback, useEffect, useState } from 'react';
import { errorText, fetchRoom, type RoomState } from './rooms.ts';
import { supabase } from './supabase.ts';

/**
 * Live room state. Refetches the whole room on any Postgres change (rooms are tiny) and on
 * (re)subscribe, so missed events heal themselves. `presenceKey` (a phone's player id) marks
 * that phone online; the big screen passes none and only listens.
 */
export function useRoom(code: string, presenceKey?: string) {
  const [state, setState] = useState<RoomState | null>(null);
  const [online, setOnline] = useState<ReadonlySet<string>>(new Set());
  const [error, setError] = useState<string | null>(null);

  const refresh = useCallback(async () => {
    try {
      const next = await fetchRoom(code);
      if (next) setState(next);
      else setError(errorText('room_not_found'));
    } catch (e) {
      setError(errorText(e));
    }
  }, [code]);

  useEffect(() => {
    void refresh();
  }, [refresh]);

  const roomId = state?.room.id;
  useEffect(() => {
    if (!roomId) return;
    const channel = supabase.channel(
      `room:${roomId}`,
      presenceKey ? { config: { presence: { key: presenceKey } } } : undefined,
    );
    channel
      .on(
        'postgres_changes',
        { event: '*', schema: 'public', table: 'rooms', filter: `id=eq.${roomId}` },
        () => void refresh(),
      )
      .on(
        'postgres_changes',
        { event: '*', schema: 'public', table: 'room_players', filter: `room_id=eq.${roomId}` },
        () => void refresh(),
      )
      .on('presence', { event: 'sync' }, () => setOnline(new Set(Object.keys(channel.presenceState()))))
      .subscribe((status) => {
        if (status !== 'SUBSCRIBED') return;
        if (presenceKey) void channel.track({});
        void refresh();
      });
    return () => {
      void supabase.removeChannel(channel);
    };
  }, [roomId, presenceKey, refresh]);

  return { state, online, error, refresh };
}
```
